# Nothing Profile

Генератор GitHub README в стиле Nothing OS. Основан на [Expressive Profile](https://github.com/metawka/expressive-profile) (MIT, metawka), с новым оформлением редактора и SVG-карточек.

## Запуск

Нужен Node.js 22.12+ с npm.

```sh
npm install
npm run dev
```

Редактор: http://localhost:5230. При уже установленных зависимостях можно запустить `node scripts/dev.mjs`.

```sh
npm run build
npm test
```

Сборка сайта находится в `dist/`, генератор для GitHub Action — в `action/render.mjs`. Сайт можно разместить на любом статическом хостинге, включая GitHub Pages; пути сборки относительные.

## Оформление

- MatrixSans Print для точечных заголовков и цифр, Geist Mono для текста, Oranienbaum для варианта Essential. Все три шрифта поддерживают кириллицу и поставляются локально.
- Произвольный цвет акцента, готовые цвета, извлечение цвета из картинки или аватара. Режимы Signal, Bold signal, Monochrome.
- Варианты Glyph / Matrix и Essential / Serif, скругление от 0 до 32 px (по умолчанию 19).
- Отдельные переключатели появления, точечной волны и Glyph-пульсации; скорость от 0.25× до 3×; общий выключатель анимаций.
- Светлая, тёмная и системная темы. SVG экспортируются для обеих тем.
- Сохранение настроек в браузере, ссылка на конфигурацию, перестановка и скрытие блоков, русская и английская версии.

Настройки находятся в панели «Стиль». В README действуют CSS-анимации внутри SVG; интерактивные элементы редактора в README не переносятся. Системное уменьшение движения отключает анимации.

## Установка README

Введите свой GitHub username, настройте блоки, нажмите кнопку скачивания и выберите ZIP. Распакуйте архив в публичный репозиторий, названный как ваш username, включая скрытые `.profile` и `.github`.

Архив содержит `profile.json`, SVG, README, иконки, лицензии шрифтов и собственный `.profile/render.mjs`. Почасовой workflow запускает этот генератор напрямую, поэтому оформление Nothing и выбранные эффекты сохраняются при обновлении. Настройки можно менять в `profile.json` или заново экспортировать в редакторе.

Встроенная установка через GitHub сохранена из upstream: она использует его публичный OAuth device-flow proxy. Ручная установка ZIP не зависит от этого proxy. Для независимого развёртывания своего proxy используйте исходники `proxy/` и измените `AUTH` в `src/app/install.ts`. Реальная авторизация и публикация в аккаунт пользователя в этой локальной версии не выполнялись.

`example/` содержит тестовый README с демонстрационными данными, это не статистика владельца проекта.
